# Customer Behavior Analysis (End-to-End Data Analytics Project)

Project Overview:
This project is an end-to-end data analytics solution built using Python, SQL, and Power BI to analyze customer shopping behavior and generate actionable business insights.

Tools & Technologies:
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- PostgreSQL (SQL)
- Power BI
- Jupyter Notebook

Key Analysis:
- Data cleaning and preprocessing
- SQL-based business queries
- Dashboard visualization
